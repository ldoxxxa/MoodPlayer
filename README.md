## Features
* Select from multiple moods (e.g. Happy, Sad, Energetic, Calm etc.)
* Automatic filtering of songs matching the selected mood
* Displays filtered songs as a clear, scrollable playlist
* Play/Pause,skip/skip back, schuffle on/off, adjust volume
* Switch from Playlist view to Player view and vise versa

## Getting Started
Prerequisites: JDK 21 installed

```bash
git clone https://github.com/mtewo/MoodPlayer.git
cd MoodPlayer
./gradlew run
```
