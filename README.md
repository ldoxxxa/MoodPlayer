# MoodPlayer — Mood-Based Music Player

**Semester project for the “Interactive Application Development” module**  
University of Applied Science RheinMain | Winter Semester 2025


---

## 📌 About the Project

MoodPlayer is a JavaFX desktop application that filters songs based on the user's current mood and automatically creates a matching playlist.

Developed as a team project, the application combines mood-based music selection with playlist management and playback controls.

---

## ✨ Features

- Choose from multiple moods, including Happy, Sad, Energetic, and Calm.
- Automatically filter songs to match the selected mood.
- Browse matching songs in a clear, scrollable playlist.
- Play and pause music.
- Skip to the next or previous track.
- Enable or disable shuffle.
- Adjust the playback volume.
- Switch between the playlist and player views.

## 🚀 Getting Started

### Requirements

- Java Development Kit (JDK) 21

### Run the Application

1. Download or clone this repository.
2. Open a terminal in the project folder containing `build.gradle`.
3. Start the application using the Gradle wrapper.

**macOS / Linux**

```bash
chmod +x gradlew
./gradlew run
```

**Windows**

```powershell
.\gradlew.bat run
```

4. Select your mood in the application to create a matching playlist.
